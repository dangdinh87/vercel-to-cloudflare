Glossary

Cloudflare Worker
Code that runs on Cloudflare's servers per request. Billed by requests + CPU milliseconds, not by waiting time.
OpenNext
The adapter (@opennextjs/cloudflare) that turns a Next.js build into a Worker.
Build-time vs request-time
Build-time code runs once when you deploy (safe to read files). Request-time code runs for each visitor — this is what must work on Workers and what you pay for.
SSG / ISR / dynamic
SSG: page built at deploy. ISR: cached page rebuilt every N seconds. Dynamic: rendered on every request (most expensive).
P0 / P1 / P2 / P3
P0 = blocks the move. P1 = will break or cost a lot, fix before moving. P2 = should fix. P3 = nice to know. INFO = checked, OK.
CPU-ms
Milliseconds the CPU actually works on a request. Workers Paid includes 30 million per month.
CDN request / function invocation
CDN request = any request (incl. images, JS). Function invocation = a request that ran your server code.
FOT / FDT
Vercel transfer charges: Fast Origin Transfer = bytes from your functions to the CDN; Fast Data Transfer = bytes to visitors. Neither is billed on Cloudflare.
R2 / D1 / Durable Objects
Cloudflare storage used by OpenNext for page cache (R2), revalidation tags (D1) and the refresh queue (DO).
Cache interception
OpenNext option that serves cached pages before loading the Next.js server — the biggest CPU saving.
Hobby / Pro
Vercel plans. Hobby is free but non-commercial only (payments, ads); Pro is paid per seat with a usage credit.
